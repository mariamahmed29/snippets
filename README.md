# Snippets

A web application that allows users to store, organize, and manage code snippets in a simple and user-friendly interface. The application uses Local Storage to save data, ensuring snippets remain available even after refreshing the page.

## Features

- Add new code snippets
- Edit existing snippets
- Delete snippets
- Store data using Local Storage
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript
- Local Storage
